# Update phonenumber while creating a message to owner


Sometimes I notice I have entered an incorrect phone number for an owner. If I'm sending messages
to multiple owners, I would have to mark the message as sent to continue with next one and
at some point edit the incorrect number and then send a message to the owner. I could also
cancel the process, update phone number and start again.

I would like to be able to edit the phone number in the middle of the process of sending multiple
messages. There could be a "edit phone number" link that, when clicked, open an inline editor with
the current phone number inserted. I can either make changes and submit, or cancel. 

If I change the number and save, the phone number in the form is updated inline. If I cancel editing,
nothing happens.
