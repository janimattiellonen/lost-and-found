# Mark discs for retrieval

Note: this is a feature that is currently only available if CLUB_ID = 2 (Talin Tallaajat).

Lost and found discs for club Talin Tallaajat: the discs are by default stored in the club's own
storage. Sometimes disc owners ask if they can retrieve the disc from my house or if I can mail the disc.

In such cases I currently copy their phone number and disc details from the sms and paste them into
a notepad app on my phone. When I retrieve a disc from the storage I mark the disc as retrieved in the note.

This is tedious. Instead, I'd like to be able to mark the disc for retrieval from the storage using the web
app. All discs marked for retrieval can then be seen on a new page that lists all discs marked for
retrieval. NOTE: in this case retrieval really means me fetching the disc form the club's storage and
must not be mixed with the owner picking up the disc from me.

When I visit the storage, I can the review the list to see, what I need to pick up.

The following information is what I usually write down manually in my notes:

- disc description (name, color)
- when was the disc registered (date)
- owner's phonenumber
- owner return preference (shipping or pickup)

Here are some example lines (fake phonenumbers):

- punainen Destroyer, 21.8, 050 111 2222, nouto
- keltainen Mako3, 11.8, 040 222 4343, postitus

The new page is of course only available for a signed in person and whatever actions the page holds.
I should also be able to mark the discs as retrieved -> disc is removed from the retrieval list

When there are discs on the retrieval list, show tye amount of items on the list in parentheses after the
"Noutolista" menu item. It allows me to quickly see if there are something I need to retrieve.
This menu item is of course only visible if I'm signed in.
